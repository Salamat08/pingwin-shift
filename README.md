# Смена менеджера — Pingwin Premium

Пиксельная point-and-click игра про одну пятничную смену менеджера в Pingwin Premium (караоке, VIP-залы, боулинг).

- Пролог и 5 глав: брони, боулинг, тишина в VIP, сцена в зале, пропавшее кольцо.
- Шкалы «Гости / Команда / Касса», сумка с предметами, мини-игры, сохранение по главам.
- Фоны и персонажи сгенерированы в Higgsfield по фото и схеме заведения.

## Запуск

Нужен любой статический сервер (картинки и `atlas.json` грузятся через fetch):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для публикации подойдёт GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Структура

- `index.html` — вся игра (движок, сцены, диалоги, мини-игры).
- `assets/bg/*.webp` — фоны залов.
- `assets/atlas.png`, `assets/atlas.json` — спрайты персонажей, кадры ходьбы и поз, иконки.
- `assets/rig.*` — части тела менеджера (запасной вариант анимации).
- `tools/build_assets.py` — сборка ассетов из исходных картинок Higgsfield.
